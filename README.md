# Информатика 6–11 класс

Интерактивный сайт с упражнениями по школьной информатике.

## Что внутри

- **6–11 классы** — по 12 основных упражнений на каждый класс
- **10 и 11 классы** — дополнительные усложнённые задания
- Тесты с выбором ответа и задания с вводом ответа
- Прогресс сохраняется в браузере (localStorage)
- Полностью статический сайт — работает без сервера

## Как открыть локально

Просто открой файл `index.html` в браузере  
(или запусти любой статический сервер, например `python -m http.server 8080`).

**Не нужно** запускать на порту 3000 и ставить Node.js.

## Как сделать публичным на GitHub Pages

1. Создай новый репозиторий на GitHub (например `informatics-6-11`).
2. Загрузи все файлы из этой папки в репозиторий:
   ```
   index.html
   css/
   js/
   README.md
   ```
3. В настройках репозитория:
   - **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: `main` (или `master`), папка `/ (root)`
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ТВОЙ_НИК.github.io/informatics-6-11/`
