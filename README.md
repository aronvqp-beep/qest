# Квест по информатике 6–11

Интерактивный сайт: теория, тесты и **задания на написание кода** (Python).

## Возможности

- Яркие кнопки классов 6–11 (стиль «квеста»)
- По 12 заданий на класс + усложнённые для 10–11
- **Редактор кода** с кнопкой «Запустить» — ученик пишет Python сам
- Теория, пример и подсказка к каждому заданию
- Прогресс сохраняется в браузере

## Как открыть

Открой `index.html` в браузере. Сервер не нужен.

## GitHub Pages

1. Создай репозиторий и загрузи все файлы
2. Settings → Pages → Deploy from branch → main / root
3. Сайт будет по адресу `https://НИК.github.io/ИМЯ_РЕПО/`
