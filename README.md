# Квест по информатике 6–11

Теория, тесты и **задания на написание кода** (Python) + 5 больших квест-задач.

## Что нового
- Усложнённые code-задания (формулы, циклы, функции, фильтры)
- Подсказки **не содержат готовое решение** — только направление
- 5 квестов ★: шифр Цезаря, анализ оценок, продолжение ряда, диагональ матрицы, частоты

## Запуск
Открой `index.html` в браузере (сервер не нужен).
